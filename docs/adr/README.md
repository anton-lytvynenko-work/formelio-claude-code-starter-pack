# Architecture Decision Records (ADRs)

Use ADRs for decisions that are:

- Expensive to reverse
- Likely to be questioned later (“why did we do this?”)
- Cross-cutting (affects many files/teams)

## How To Add One

1. Copy `docs/adr/000-template.md`
2. Name it `docs/adr/NNN-short-title.md`
3. Link it from `docs/architecture.md`

## Status Values

- `proposed` — not yet agreed
- `accepted` — current decision
- `superseded` — replaced by a newer ADR
