# Tasks

Use this folder for planning and collaboration:

- Feature/task breakdowns (`tasks/<feature>.md`)
- Scratchpads for multi-agent work (`tasks/scratchpad-1.md`, etc.)

## Conventions

- Use checkboxes as the source of truth.
- Status markers:
  - `[ ]` not started
  - `[~]` in progress
  - `[x]` done

## Template

Start from `tasks/_template.md` (copy it to a new file).
